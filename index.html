Tutorial de Instalação

Para instalar a lista de IPTV no seu dispositivo siga os passos abaixo:

1. Baixe o aplicativo IPTV no seu dispositivo

2. Abra o aplicativo e clique em adicionar lista

3. Cole o link da lista de IPTV no campo indicado

4. Clique em salvar e pronto, você já pode assistir a lista de IPTV
